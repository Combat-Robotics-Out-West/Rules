
# Usage

robot_construction_rules: Rules specifying what is required to build a robot eligible to compete
match_rules: Rules specifying how matches are fought and won safely

Tournament rules are not standardised at this time and will depend on each event due to time and attendance uncertainties. This may change in the future.

The currently applied ruleset will always be on the main branch. Development or alternate rules may be on other branches, events may choose to use these if desired, and every effort will be made to communicate differences to attendees.

Markdown (.md) files are always the source of truth, if there are any conflicts refer to the markdown file, and open an issue or inform an admin. Other files may be included in this repository (such as pdfs) to make the rules more accesible.


# Origin

Rules are originally based on multiple sources, including but not limited to:
 - SPARC Robot Construction Specifications v1.2
 - SPARCMatch Rules v1.3
 - Robot Royal Ruleset
 - NHRL Ruleset

 Interpretations and ruling on specific applications from these rulesets are not guaranteed to be accepted at C.R.O.W. events.
